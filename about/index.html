About

StreamerOS Dev Tools is a small set of free utilities for developers: a JSON formatter and validator, a Base64 encoder and decoder, and short guides that explain the formats behind them.

It is built and maintained by Yaseen Khatib, a full-stack AI engineer, as part of the StreamerOS project. The tools exist because the common ones are often cluttered, slow or unclear about what happens to the text you paste.

How the tools work

Every tool runs in your browser using standard JavaScript. The text you enter is processed on your device and is not sent to a server or stored. The site is a static website hosted on GitHub Pages.

How the site is funded

The tools are free. The site may show Google AdSense ads to cover hosting and development time. Ads never change the output of a tool.

Corrections

If a result is wrong or a guide contains a mistake, please use the contact page. Fixes are made in the open and the guides are updated.
