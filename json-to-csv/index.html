JSON to CSV Converter

Turn a JSON array into a CSV file for Excel or Google Sheets. Nested objects are flattened, the delimiter is yours to choose, and nothing is uploaded.

Paste a JSON array of objects, then press Convert.

What the converter does

CSV is a table: one header row, then one row per record. JSON is a tree. This tool turns a JSON array of objects into that table. Each object is a row, each key is a column, and nested objects are flattened into columns with dotted names. The result can be copied or downloaded as data.csv.

How to convert JSON to CSV

  1. Paste a JSON array of objects, or press Sample.
  2. Pick a delimiter and decide whether to flatten nested objects, then press Convert.
  3. Press Copy or Download .csv.

Example

[{"id":1,"name":"Ada","address":{"city":"London"}},
 {"id":2,"name":"Grace, Rear Adm.","address":{"city":"New York"}}]

becomes

id,name,address.city
1,Ada,London
2,"Grace, Rear Adm.",New York

Note the quotes around the second name: a field containing the delimiter is quoted, as RFC 4180 requires. With Flatten nested objects turned off, the third column is called address and holds the JSON text {"city":"London"}, quoted, because it contains quote marks.

A second example, with an array, a null and a key that only one record has:

[{"id":1,"name":"Ada","tags":["a","b"],"note":null},
 {"id":2,"extra":true}]
id,name,tags,note,extra
1,Ada,"[""a"",""b""]",,
2,,,,true

How each JSON value becomes a cell

stringThe text as it is, quoted if it needs to be
numberThe number as JavaScript writes it. Very large or small values can use exponent form, such as 1e+21, and integers above 2^53 lose digits.
true, falsetrue, false
null, or a key the object lacksAn empty cell
arrayOne cell holding the array as JSON text, for example ["a","b"]
nested object, Flatten onOne column per leaf, named with dots, such as address.city. An empty object gives an empty cell.
nested object, Flatten offOne cell holding the object as JSON text
an item that is not an object, such as 5 or "x"A row with the value in a column called value
a single object instead of an arrayOne row

How the columns are chosen

The header row is the union of every key found in any object, in the order each key first appears. If an object lacks a key, its cell is left empty. This means rows with different shapes still line up under the right columns.

Quoting, delimiters and line endings

RFC 4180 describes CSV with a comma between fields, a CRLF line break between records, double quotes around any field that contains a comma, a double quote or a line break, and a doubled double quote to write a quote inside a field. The tool follows those rules for whichever delimiter you choose, so a field is quoted when it contains the delimiter, a quote or a line break. Semicolon and tab are common variants that the RFC does not cover. Records are separated by CRLF, and there is no line break after the last one.

Things to watch for

  • Dots in keys. A key that already contains a dot, such as a.b, and a nested a with a b inside give the same column name. When both are in one record, the later one overwrites the earlier.
  • Arrays are not expanded. A record with a list of five items still produces one row. If you want one row per item, restructure the JSON first.
  • Text that looks like a formula. Values starting with =, +, - or @ are written unchanged. Check data you do not trust before opening it in a spreadsheet.
  • Invalid input. Only valid JSON converts. The error shows the line and column; the JSON validator lists each message and fix.

Convert JSON to CSV in code

Python, standard library only. This flattens nested objects the same way as this page and writes out.csv from a data.json holding an array of objects. On a test file with nested objects, an array, a null, an empty object and a name needing quotes, it produced the same CSV as the tool, plus a final line break:

import csv
import json


def flatten(value, prefix=""):
    """Nested objects become dotted keys; everything else is one cell."""
    if isinstance(value, dict):
        if not value:
            return {prefix or "value": ""}
        out = {}
        for key, item in value.items():
            out.update(flatten(item, f"{prefix}.{key}" if prefix else key))
        return out
    return {prefix or "value": value}


def cell(value):
    if value is None:
        return ""
    if isinstance(value, str):
        return value
    return json.dumps(value, separators=(",", ":"))


with open("data.json", encoding="utf-8") as f:
    data = json.load(f)
rows = [flatten(r) for r in (data if isinstance(data, list) else [data])]

headers = []
for row in rows:
    for key in row:
        if key not in headers:
            headers.append(key)

with open("out.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f, lineterminator="\r\n")
    writer.writerow(headers)
    for row in rows:
        writer.writerow([cell(row.get(h)) for h in headers])

Open the output file with newline="", as above, or Python on Windows writes an extra carriage return. For a flat array of objects (no nesting) on Windows, PowerShell does it in two lines. This was tested in Windows PowerShell 5.1; it quotes every field and does not flatten nested objects:

$rows = Get-Content -Raw flat.json | ConvertFrom-Json
$rows | Export-Csv -NoTypeInformation -Encoding UTF8 -Path flat.csv

Limits of this tool

  • It converts JSON to CSV only. It does not convert back.
  • It reads pasted text. There is no file upload, and a very large paste is slow.
  • Values stay text or numbers as JSON gave them. It does not format dates or add column types.
  • Everything runs in your browser. The tool's code does not send what you paste anywhere; see the privacy policy for the analytics the site does run.

To read a document before converting it, open it in the JSON viewer or tidy it with the JSON formatter. The guide to JSON parse errors helps when the input will not parse.

Frequently asked questions

What JSON shape converts best?

An array of objects, like [{"id":1},{"id":2}]. Each object becomes a row and each key becomes a column. A single object becomes one row.

What happens to nested objects?

With Flatten nested objects on, nested keys become dotted column names, so {"address":{"city":"London"}} gives a column called address.city. With it off, the nested object is written into one cell as JSON text.

What happens to arrays inside a row?

An array is written into a single cell as JSON text, for example ["a","b"]. Splitting arrays into extra columns or rows would change the shape of your data, so the tool does not guess.

Why are some cells empty?

A cell is empty when the object has no such key, when the value is null, or when the value is an empty object and Flatten is on. Rows with different keys still line up, because the header row is the union of all keys.

Why is there a column called value?

When an item in the array is not an object, such as a number, a string or a nested array, there is no key to use as a column name. The tool puts it in a column called value. The same happens if the whole JSON is a single number or string.

Will it open correctly in Excel?

The downloaded file includes a UTF-8 byte-order mark, which helps Excel read accents and non-Latin text correctly. The Copy button does not add it. In some regions Excel expects a semicolon delimiter, which you can choose.

Is there a security risk opening the CSV?

If a value starts with =, +, - or @, a spreadsheet may treat it as a formula. The tool does not change values, so review CSV from untrusted JSON before opening it in Excel or Google Sheets.

Can I convert CSV back to JSON?

Not on this site. This tool only goes from JSON to CSV, and flattening is not reversible: the dotted column names and the JSON text in array cells would need to be turned back into structure by your own code.

Is my data uploaded?

No. The conversion runs in your browser, and the CSV is generated on your device. The page's code makes no network request with your text. The site does run page-level analytics, described in the privacy policy, but that does not include what you paste.
